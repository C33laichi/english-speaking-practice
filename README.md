# 🔤 句拼乐 · 英语逐词拼写训练

一个类似「句乐部」的英语听写训练网站：**听发音 → 逐词打字 → 字母级即时校验**。纯前端单页应用，零依赖、零构建，克隆下来就能跑。

![运行效果](screenshot-final.png)

## ✨ 功能特性

- 🎧 **发音复述**：基于浏览器 Web Speech API 的 TTS 发音，支持重播、慢速模式、美音/英音切换、多档语速
- ⌨️ **句乐部式逐词打字**：句子拆分为一个个词槽（下划线提示字母数），光标自动跟随，专注打当前词
- 🔴 **字母级即时校验**：打错一个字母立刻红色高亮，无需等整句打完；退格可修正
- 📝 **空格提交确认**：
  - 全对 → 词槽变绿锁定，连击 +1，并朗读该词
  - 有误 → 词槽抖动 + 清空重打
  - 连续 3 次打错 → 自动揭晓答案（红底 + ✗），跳到下一词
- 🏆 **评级系统**：Perfect! / Great! / Good / 再接再厉，附每词绿/黄/红分类
- 📚 **双练习模式**：
  - **听音拼句**：内置 60 句题库，按难度（初级/中级/高级）× 场景（日常/校园/职场/旅行等）分类
  - **听音拼词**：内置 3500 词库（3288 个有效单词），可按单词长度筛选
- 💡 提示功能（首字母 + 中文译文）、跳过、复读
- 📊 **本地统计**：练习数、正确率、连对记录、掌握进度（localStorage 持久化，不上传任何数据）
- ⌨️ 快捷键：`Enter` 检查/下一题，`Ctrl+Enter` 重播发音；标点不参与判分

## 💻 本地运行

项目是纯静态页面，但**必须通过 HTTP 服务器访问**（浏览器禁止 `file://` 协议下的 `fetch` 请求本地文件），任选一种方式：

**方式一：Python（推荐，系统自带即可）**

```bash
cd english-speaking-practice
python -m http.server 3000
```

**方式二：Node.js**

```bash
cd english-speaking-practice
npx serve -l 3000 .
```

然后浏览器打开 <http://localhost:3000> 即可。

> 无需 `npm install`，没有任何第三方依赖，也不需要构建步骤。

## 🌐 浏览器要求

- 需要 modern 浏览器（Chrome / Edge / Firefox / Safari 均可）
- 发音功能依赖浏览器内置的 **Web Speech API**（`speechSynthesis`）：
  - 不同系统可用的音色列表不同，程序会自动降级到默认音色
  - 部分浏览器要求用户先与页面交互后才允许播放语音（本项目首次点击按钮后即正常）
  - 推荐 Chrome 或 Edge，发音质量最佳

## 📁 目录结构

```
english-speaking-practice/
├── index.html          # 页面结构
├── css/
│   └── style.css       # 全部样式（词槽/连击/评级/动画）
├── js/
│   ├── app.js          # 核心逻辑：打字引擎、TTS、校验、统计
│   └── sentences.js    # 句子题库（60 句，分级分场景）
└── data/
    └── words.txt       # 单词库（约 3500 词）
```

## 🛠️ 自定义题库

- **加句子**：编辑 `js/sentences.js`，按现有格式追加 `{ text: "...", zh: "..." }` 即可
- **换单词库**：替换 `data/words.txt`，每行一个单词（含中文释义亦可，程序只取英文部分）
